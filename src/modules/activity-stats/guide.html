Profile Page - Activity Panel

Visit any player's profile to see an Activity Stats panel at the bottom. Select a time period (3d, 1w, 2w, 1mo, 6mo, 1yr) to view stats like Xanax, Activity hours, Attacks won, Respect, Retals, Travel, SEs, and Networth change.

Click Export to copy a text summary to your clipboard for easy sharing.

Faction Page - Member Stats Table

On faction pages, two extra columns (A = activity hours, X = xanax taken) are injected into the member table. Select a period and click Load Data to fetch stats for all members.

Results are cached for 24 hours. Click the ↻ button to force a fresh pull. Click column headers to sort.

API Key

This module uses the API key configured in the DSS Setup page. A Public key is sufficient for profile stats, but Limited Access is recommended for faction member stats.
