What It Does

On the faction Organized Crimes page, this module:

• Sorts crime role slots by weight priority (highest weight first) so you can quickly see which roles matter most.

• Adds a weight label above each role slot showing the role's contribution percentage.

• Colour-codes each slot's left border from green (highest weight) to red (lowest weight).

• Calculates and displays the overall success chance for each crime based on the filled slots' CPR values.

Recruiting Panel Ordering

On the Recruiting panel, crimes are reordered by pause priority:

• Paused crimes go to the top (fewest empty slots first) with a red outline.

• Crimes that will pause within 24h come next, soonest first.

• Crimes still recruiting (no countdown yet) follow, fewest empty slots first.

• Crimes that pause more than 24h out go last, soonest first.

Each crime gets a label such as Priority #1 - Paused, Priority #2 - 5h 12m or Priority #3 - Recruiting. Pause time is the execution countdown minus 24h for each empty slot.

OC Join Reminder (all pages)

While this module is enabled, a reminder also runs on every Torn page. Whenever you're not currently in an organised crime, a blue prompt appears with a button that takes you straight to your faction's crimes page to join one. Dismissing it (the × or Dismiss button) hides it for 2 minutes, after which it returns if you still haven't joined.

It's tied to this module — there's no separate switch. It uses the API key from the DSS Setup page and is deliberately sparing with it: the result is cached and shared across all your open tabs, and while you're already in a crime it barely checks at all, waiting until the crime is due to be ready before looking again.

Completed Crimes

On the Completed tab, each crime shows a Completed: date time badge to the left of its success box, read from the Torn API's executed_at value.

A date filter above the list lets you show only crimes completed within a From–To date range. Both bounds are inclusive of the whole day.

Join Button Restrictions

For Family X members, join buttons are disabled when your CPR is below the minimum required for that role.

Hover (or tap on mobile) a disabled button to see the required CPR. This prevents members from joining roles they aren't ready for.

For all other factions, role sorting and weight labels still work but join buttons are never restricted.

Low CPR Highlighting

When enabled, members on the Recruiting and Planning tabs whose CPR is below the minimum set for their role get a red outline and a CPR x / min y strip at the bottom of their slot.

Open slots, unpaid roles and the Completed tab are ignored. Applies to the same factions as the join button restrictions.

Success Chance Display

A colour-coded Success: XX% badge appears on each crime panel, calculated from the CPR values of all filled slots using the tornprobability.com API.

Colours range from green (90%+) through yellow/orange to red (<40%).

Third-Party Data Sharing

To calculate success chances, this module sends crime role names and CPR success-chance values (read from the page) to tornprobability.com. Your API key is never sent to this service — only the numeric values needed for the calculation.

This data is shared with the tornprobability service owners under their terms of service. If you disable this module, no data is sent.

Keyboard Shortcut

Press Ctrl+Shift+P to force a re-process of all visible crimes (useful if the page updated and sorting didn't trigger).
