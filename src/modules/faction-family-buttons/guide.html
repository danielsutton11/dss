Faction Buttons

On your faction page, a collapsible Faction Buttons panel appears above the faction content. Add factions via the search bar, assign them types (Family, Friend, Reviver, Merc), and click the coloured buttons to navigate directly to their pages.

Editing Factions

Click the ✎ edit button to open the search bar and edit panel. Search for factions by name, reorder within groups using ▲/▼, change types, toggle visibility, or delete entries. Changes apply instantly.

Settings

Per Row — choose how many buttons per row (2–5). Hidden on mobile where it defaults to 2.

All Profiles — when enabled, shows buttons on all configured faction profile pages, not just family type.

API Key

This module uses the API key configured in the DSS Setup page for faction search and faction ID detection.
