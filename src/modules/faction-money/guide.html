Payment Processing

On the faction Controls tab, a Process Faction Payments button appears. Click it to open an input modal where you can enter payment instructions.

Payments are processed one at a time — click Process Next Payment for each entry. Results show in a live table with previous balance, change, and new balance.

Input Methods

Manual Entry — paste a JSON array: [[userID, amount], [userID, amount]]

Upload File — drag and drop or browse for a .txt/.csv file with userID,amount per line.

Undo Payments

After processing, click Undo Next Payment to reverse each payment one at a time. Each click undoes the most recent payment that hasn't been reversed yet.
