Display Mode

Overlay — keeps the honor bar artwork (slightly dimmed) and puts the name on top in a clear font with a dark pill behind it.

Plain — hides the artwork and shows just the name. Most readable, best for dense lists.

Hover — bars look normal; hover (or tap) one to see the clean name.

Notes

Changes apply instantly on open pages. Long names are truncated with an ellipsis; the full name is still in the link's tooltip.

This only adds a label on top of Torn's honor bars — it doesn't change or remove Torn's own elements, so other scripts keep working.
