What It Does

On the Hospital View page, adds a filter bar above the list to show only the players you want to revive.

Filters

• Revivable Only — hides players whose revive button is unavailable.

• Online / Idle / Offline — show or hide by activity status.

• Time slider — set a max hospital time remaining (0–100h).

• Level slider — set a max player level (0–100).

Pagination

All filters re-apply automatically when the list updates via pagination.
