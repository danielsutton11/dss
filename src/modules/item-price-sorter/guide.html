Price Sorting

A sort button appears next to the item search bar. Click to cycle through:

Unsorted → High → Low → Low → High → back to Unsorted.

On mobile / PDA the button shows as a compact symbol (⇅ → $↓ → $↑) to fit the toolbar.

Sorting carries over when switching item tabs. The original order is preserved and can be restored.

Stacks & Totals

Stacks sort by their total value — unit price × quantity — so a pile of 500 cheap items is ranked by what the whole pile is worth, not by the single-item price. Single items sort by their unit price.

Each stack shows both figures: unit price | quantity× = total.

Price Data Source

Desktop: reads price data injected by the TornTools browser extension. Install it from the Chrome Web Store or Firefox Add-ons.

Mobile / Torn PDA: TornTools isn't available, so prices are pulled from the Torn API (/torn/items) using the API key set on the DSS Setup page, and shown as a small tag at the right of each row.

Items with no market price (untradeable or event items) show N/A and sort to the bottom.

Daily Prices & Freshness

Market prices update roughly once a day, so the data is cached and refreshed at most once per day — on your first visit to the items page each day. Repeat visits use the cache and make no extra API calls.

If a daily refresh fails (no connection, API error), the last saved prices are used instead. When that happens the prices turn red and a banner shows the date the data is from — reload the page to try refreshing again.
