What It Does

When you are in hospital, a green NITE Revive Me button is added to the top page links. Clicking it sends a revive request to Midnight X.

Payment

On a successful standard request you'll be asked to pay your reviver 2 Xanax or $1.8m. Contract requests are handled without the payment prompt.

Third-Party Data Sharing

This module sends your Torn ID and username (read from the sidebar session data) to api.no1irishstig.co.uk, the Midnight X revive service, so a reviver can be dispatched. Your API key is never sent. If you disable this module, no data is sent.

Notes

The button only appears while you're in hospital and is removed automatically when you leave. It runs on every Torn page since hospital status can change anywhere.
