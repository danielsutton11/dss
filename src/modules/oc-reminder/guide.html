What It Does

Checks whether you are currently in an organised crime. If you're not, a blue reminder appears with a button that takes you straight to your faction's crimes page so you can join one.

The reminder is not shown to Recruits (or players without a faction), since they can't join a crime yet. Your faction position is re-checked hourly, so the reminder starts automatically after you're promoted.

Dismiss

Dismissing the reminder (the × or Dismiss button) hides it for 2 minutes. After that, if you still haven't joined a crime, it reappears.

API Usage

This module uses the API key configured in the DSS Setup page. To keep API usage low, the result is cached and shared across all your open tabs — while you're in a crime it barely checks at all (it waits until the crime is due to be ready). Before showing the reminder it always confirms you're still not in a crime, so it won't nag you right after you've joined. Your faction position is looked up at most once an hour.
