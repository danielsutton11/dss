What it does

Replaces the ranked war member list on the faction war page with Tyronic war data, drawn natively in Torn: dibs and assists, live hospital/jail timers, stat estimates, travel landing times, activity, roll call and the merc list.

Statuses update instantly from Torn's own page data; if Tyronic falls behind, the panel switches to a light Torn API fallback on its own.

Setup

Uses the API key from your DSS settings. To use a different key, open the panel's ⚙ settings on the war page.

Your faction must be on Tyronic. Refresh rate, warnings, presence and columns are all set from the panel's ⚙ menu.

If you had the standalone Torn War -> Tyronic Native Panel script installed, disable it - only one panel runs at a time.

Tips

Torn list swaps back to Torn's own list at any time. The strip under the score header shows our faction's finished attacks as they land.
